# test-project

A Node.js web app built with **Next.js** and **TypeScript**.

## Tech stack

- Node.js
- TypeScript
- Next.js (App Router)
- dotenv for environment variables

## Getting started

**Requirements:** Node.js 18+ and npm.

```bash
npm install
```

Next.js is not scaffolded in this repo yet. After it is added, start the dev server with:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project conventions

- Write application code in TypeScript.
- Use the App Router (`app/`).
- Prefer Server Components; add `"use client"` only when needed.
- Put API routes under `app/api/`.
